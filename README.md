# בוט טלגרם להורדת תכנים

בוט טלגרם שמוריד תכנים מיוטיוב, אינסטגרם, טיקטוק, ועוד אלפי אתרים (בזכות [yt-dlp](https://github.com/yt-dlp/yt-dlp)).
שולחים לבוט קישור, בוחרים וידאו או אודיו (mp3), והבוט שולח את הקובץ בחזרה בצ'אט.

## שלב 1 - יצירת הבוט בטלגרם (אם עדיין אין לך)

1. פתח בטלגרם שיחה עם [@BotFather](https://t.me/BotFather).
2. שלח את הפקודה `/newbot`.
3. תן לבוט שם תצוגה (כל שם, למשל "המוריד שלי").
4. תן לו username שמסתיים ב-`bot`, למשל `eli_downloader_bot`.
5. BotFather יחזיר לך הודעה עם **טוקן** שנראה כך:
   `123456789:AAExampleTokenExampleTokenExample`
6. שמור את הטוקן הזה - הוא הסוד שמזהה את הבוט שלך. אל תשתף אותו עם אף אחד.

## שלב 2 - התקנת התוכנה על המחשב/שרת

דרוש Python 3.9+ מותקן.

```bash
# בתוך תיקיית הפרויקט:
python -m venv venv
source venv/bin/activate        # בווינדוס: venv\Scripts\activate

pip install -r requirements.txt
```

בנוסף חובה להתקין **ffmpeg** (נדרש כדי לאחד וידאו+אודיו ולהמיר ל-mp3):

- **Ubuntu/Debian:** `sudo apt install ffmpeg`
- **Mac (Homebrew):** `brew install ffmpeg`
- **Windows:** הורד מ-https://ffmpeg.org/download.html והוסף את התיקייה של ffmpeg.exe ל-PATH

## שלב 3 - הגדרת הטוקן

1. צור קובץ בשם `.env` בתיקיית הפרויקט (אפשר להעתיק את `.env.example`).
2. הכנס לתוכו את הטוקן:

```
BOT_TOKEN=123456789:AAExampleTokenExampleTokenExample
```

## שלב 4 - הרצה

```bash
python bot.py
```

אם הכל תקין, תראה בטרמינל `Bot starting (polling)...`. עכשיו אפשר לפתוח את הבוט בטלגרם, לשלוח `/start`, ולשלוח קישור לניסיון.

## הערות חשובות

- **מגבלת גודל קובץ:** ל-Telegram Bot API הרגיל יש מגבלה של כ-50MB להעלאת קובץ ע"י בוט. אם התוכן גדול מזה, הבוט ידווח על כך. כדי לעקוף את המגבלה אפשר להריץ [Local Bot API Server](https://github.com/tdlib/telegram-bot-api) (מגביל עד 2GB) - זה מורכב יותר להקמה, ספר לי אם תרצה שאעזור בזה.
- **אינסטגרם/יוטיוב עם cookies:** תוכן פרטי באינסטגרם (סטוריז, פרופילים פרטיים), וגם חלק מתכני היוטיוב שדורשים "Sign in to confirm you're not a bot", דורשים קובץ cookies של חשבון מחובר. ראו הסבר מלא בסעיף "פתרון חינמי: cookies מחשבון ייעודי" למטה. בקצרה, מוסיפים בקובץ `.env`:
  ```
  COOKIES_FILE=cookies.txt
  ```
- **אתרים נתמכים:** yt-dlp תומך באלפי אתרים (יוטיוב, אינסטגרם, טיקטוק, טוויטר/X, פייסבוק, ועוד). ברוב האתרים תוכן ציבורי יעבוד "מהקופסה".
- **הרצה 24/7:** כדי שהבוט ירוץ תמיד (גם כשהמחשב שלך כבוי), כדאי להעלות אותו לשרת VPS קטן (למשל DigitalOcean/Hetzner/Oracle Cloud Free Tier) ולהריץ אותו שם עם `systemd` או `pm2`, או להשתמש ב-Docker. ספר לי אם תרצה שאכין לך את זה.

## פתרון חינמי: cookies מחשבון גוגל ייעודי (מומלץ)

חלק מהתכנים ביוטיוב (בעיקר תוכן רשמי/של חברות תקליטים) נכשלים עם השגיאה
"Sign in to confirm you're not a bot", גם עם כל הפתרונות הטכניים האחרים (Deno, PO Token).
הדרך החינמית הכי אמינה לפתור את זה היא cookies מחשבון גוגל **ייעודי** (לא חשבון אישי
שמשתמשים בו בגלישה רגילה) - כי אז אין "מתחרה" שמבטל את הסשן, והוא יכול להישאר תקף
הרבה זמן בלי לרענן אותו כל הזמן.

איך להקים:

1. פתח חשבון Google חדש (Gmail) שישמש **רק** לצורך זה - לא להתחבר איתו בשום מקום אחר
   (לא בטלפון, לא בדפדפן הרגיל שלך).
2. פתח דפדפן (עדיף פרופיל/חלון נפרד בכרום) והתחבר עם החשבון החדש בכתובת youtube.com.
3. התקן את התוסף [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc) בכרום.
4. בזמן שאתה מחובר ונמצא בעמוד youtube.com, לחץ על התוסף וייצא (Export) קובץ בשם `cookies.txt`.
5. העבר את `cookies.txt` **ישירות מהמחשב שלך לשרת** (לא דרך הצ'אט כאן!) עם scp, לתוך תיקיית הבוט בשרת:
   ```
   scp -i ~/Downloads/ssh-key-2026-08-12.key ~/Downloads/cookies.txt ubuntu@130.110.14.11:~/telegram-downloader-bot/
   ```
6. בשרת, בקובץ `.env`, הוסף שורה:
   ```
   COOKIES_FILE=cookies.txt
   ```
7. הפעל מחדש את הבוט (`sudo systemctl restart telegram-bot` אם מותקן systemd).

**חשוב:** אל תיכנס לחשבון הזה שוב מדפדפן/טלפון אחרי הייצוא - כל כניסה נוספת ממכשיר/מיקום
אחר עלולה לגרום לגוגל "לחשוד" ולפסול את הסשן, בדיוק כמו שקרה קודם עם החשבון האישי. אם
בכל זאת הסשן פג בעתיד (יכול לקרות אחרי שבועות/חודשים), פשוט חוזרים על שלבים 2-5.

## פרוקסי רזידנציאלי - חלופה בתשלום (אם גם ה-cookies לא מספיקים)

אם אחרי הגדרת cookies מחשבון ייעודי עדיין יש תכנים ספציפיים שנכשלים, ייתכן שהחסימה
מבוססת על כתובת ה-IP של השרת עצמו (מזוהה כ"datacenter IP" חשוד) ולא רק על cookies.
הפתרון היחיד לזה הוא ניתוב הבקשות דרך כתובת IP ביתית אמיתית, באמצעות שירות פרוקסי
רזידנציאלי בתשלום (למשל [Decodo](https://decodo.com), בעבר Smartproxy) - זו לא אפשרות
חינמית, ולכן מומלץ לנסות קודם את פתרון ה-cookies למעלה.

איך להפעיל:

1. הירשם לשירות פרוקסי רזידנציאלי וקבל פרטי חיבור (משתמש, סיסמה, כתובת gateway ופורט).
2. הוסף בקובץ `.env` בשרת שורה כזו (עם הפרטים שקיבלת):
   ```
   PROXY_URL=http://USER:PASS@gate.decodo.com:10001
   ```
3. הפעל מחדש את הבוט. הבוט ינתב אוטומטית כל הורדה דרך הפרוקסי הזה (אם `PROXY_URL` מוגדר).

אם לא מגדירים `PROXY_URL`, הבוט ממשיך לעבוד כרגיל בלי פרוקסי - זה משפיע רק על התוכן הבעייתי
שתואר למעלה.

**חשוב:** שירותי פרוקסי רזידנציאלי מחויבים לפי נפח (GB) שמועבר - ככל שיותר משתמשים
מורידים תוכן דרך הבוט, כך עולה הצריכה והעלות החודשית. כדאי לעקוב אחרי הצריכה בדשבורד
של ספק הפרוקסי, במיוחד אם הבוט פתוח לציבור הרחב.

## מהירות הורדה

יש כאן שתי שכבות נפרדות: מה שהקוד יכול לשפר, ומה שהוא לא יכול (מגבלת חומרה/רשת של השרת).

**מה שכבר משופר בקוד:**
- **הורדת פרגמנטים מקבילית** - פורמטים מפוצלים (DASH, נפוץ ביוטיוב) מורדים כמה חלקים
  בו-זמנית במקום אחד-אחרי-השני.
- **aria2c** (אם מותקן בשרת) - מוריד עם עד 16 חיבורים מקבילים לקובץ, שיפור משמעותי
  בפורמטים לא-מפוצלים. להתקנה: `sudo apt install -y aria2` ואז להפעיל מחדש את הבוט
  (`sudo systemctl restart telegram-bot`) - הבוט מזהה אוטומטית אם aria2c קיים ומשתמש בו.

**המגבלה שהקוד לא יכול לפתור:** שרת ה-Oracle Free Tier (`VM.Standard.E2.1.Micro`) מוגבל
ל-**עד 50 Mbps** רוחב פס לאינטרנט הציבורי, ויש לו רק **1/8 OCPU** (מעבד חלש מאוד) - שני
הגורמים האלה קובעים תקרה קשיחה: גם הורדה מיוטיוב וגם העלאה חזרה לטלגרם מוגבלות ל-50Mbps
בערך (כ-6MB לשנייה בתנאים אידיאליים, בפועל פחות), והמרת אודיו ל-mp3 או מיזוג וידאו
דרך ffmpeg לוקחים זמן בגלל המעבד החלש. שיפור אמיתי מעבר לזה דורש שרת חזק/מהיר יותר
(בתשלום) - לא משהו שאפשר לפתור בקוד על השרת החינמי הזה.
מקור: [מגבלות ה-Always Free באתר Oracle](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)

## הרצה קבועה עם systemd (השרת ימשיך לרוץ גם אחרי ניתוק/איתחול)

הפרויקט כולל קובץ `telegram-bot.service` מוכן. כדי להתקין אותו כשירות מערכת בשרת:

```bash
sudo cp telegram-bot.service /etc/systemd/system/telegram-bot.service
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
```

בדיקה שהשירות רץ:

```bash
sudo systemctl status telegram-bot
```

צפייה בלוגים:

```bash
tail -f /home/ubuntu/telegram-downloader-bot/bot.log
```

עדכון קוד בעתיד (אחרי `git pull` בשרת):

```bash
sudo systemctl restart telegram-bot
```

## פריסה על Render (הרצה 24/7 בענן)

הפרויקט כולל `Dockerfile` ו-`render.yaml` שמוכנים לפריסה על [Render](https://render.com).

**חשוב לדעת לפני שמתחילים:** ל-Render יש תוכנית חינמית, אבל היא **לא** תומכת ב-Background Worker (סוג השירות המתאים לבוט הזה, שכל הזמן "מאזין" לטלגרם ולא מריץ שרת HTTP). צוות התמיכה של Render מאשר זאת במפורש. המחיר המינימלי לבוט כזה הוא תוכנית **Starter, כ-7$/חודש**.

שלבים:

1. **העלה את קוד הפרויקט לריפו ב-GitHub** (Render נפרס מ-git, לא מ-zip):
   ```bash
   cd telegram-downloader-bot
   git init
   git add .
   git commit -m "init"
   # צור ריפו חדש וריק בגיטהאב, ואז:
   git remote add origin <כתובת-הריפו-שלך>
   git push -u origin main
   ```
   ⚠️ הקפד ש-`.env` (אם יצרת) **לא** נכנס לריפו - הוא לא צריך, כי הטוקן יוגדר בדשבורד של Render (ראה שלב 3).

2. בדשבורד של Render: **New +** → **Blueprint** → חבר את הריפו. Render יזהה אוטומטית את `render.yaml` ויציע ליצור שירות מסוג Background Worker בשמו `telegram-downloader-bot`.

3. בעת האישור, Render יבקש למלא את `BOT_TOKEN` (מוגדר ב-render.yaml כ-`sync: false`, כלומר סודי וידני) - הדבק כאן את הטוקן מ-BotFather.

4. אשר ולחץ Deploy. Render יבנה את ה-Docker image (כולל ffmpeg) ויריץ את הבוט. אפשר לעקוב אחרי הלוגים בדשבורד כדי לראות `Bot starting (polling)...`.

**עדכון גרסה בעתיד:** כל `git push` לריפו יגרום ל-Render לבנות ולפרוס מחדש אוטומטית.
